# Identifier vs Literal

## Comparison Table

| Feature | Identifier | Literal |
|---|---|---|
| Definition | A name used to identify a variable, function, class, or other element | A fixed value written directly in the code |
| Purpose | Acts as a label or reference | Represents the actual data value |
| Example | `userName`, `age`, `totalAmount` | `25`, `"Alice"`, `true` |
| Role | Points to something | Is the value itself |
| Changeability | The value it refers to can change | It is a constant value as written |

## Simple Example

```js
const userName = "Alice";
const age = 25;
```

### Breakdown

| Code | Type | Explanation |
|---|---|---|
| `userName` | Identifier | The name used to refer to the stored value |
| `"Alice"` | Literal | The actual string value assigned |
| `age` | Identifier | The name used to refer to the stored value |
| `25` | Literal | The actual number assigned |

## In Short

- An identifier is a name.
- A literal is a direct value.

So in `const age = 25;`, `age` is the identifier and `25` is the literal.
